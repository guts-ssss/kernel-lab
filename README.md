# Kernel Lab

面向 AI 编程代理的计算算子研发 Skill，通过独立实验、渐进验证和可复现证据，推动算子优化与交付。适用于 CUDA、Triton、TileLang 等项目，复用项目已有的编译、测试和性能测量工具。

## 工作方式

明确目标与基线 → 测量瓶颈 → 独立实验 → 快速筛选 → 完整验收 → 验证实际调用入口。

- **探索可追溯**：保留源码快照、实验结果和失败原因，支持继续研究与组合改进。
- **收益有依据**：分别评估正确性、数值误差、延迟和显存，对照上一合格版本与固定初始基线。
- **交付有门槛**：区分实验 `trial_001` 与合格版本 `version_001`，通过必要验证后才计为交付。
- **任务可续接**：记录运行状态、证据位置和下一步工作，支持跨会话恢复。

## 使用

在支持 Skill 的代理中加载本仓库，并给出目标算子、输入范围、硬件和验收要求，例如：

> 用 $kernel-lab 优化这个算子的前向和反向。固定当前实现为基线，降低延迟，保持现有数值精度要求和显存上限，并保留可复现的实验记录。
